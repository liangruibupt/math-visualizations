Ford 圆与 Farey 数列

在每个既约分数 p/q 处放一个与 x 轴相切、半径 1/(2q²) 的圆。任意两个圆要么相切、要么分开，从不交叠；相切当且仅当 |ps − qr| = 1。

选中的圆

单击一个圆选中它，Shift + 单击选第二个圆来比较。青色是它在 Fq 里的左右邻居（与它相切的两个最大的圆），紫色虚线是两个空隙里的中位分数，也就是空隙里最大的下一个圆；白点是它和视野里其他圆的切点。

Farey 数列 Fn

曲线是 |Fm| ÷ (3m²/π²)，m = 1…1000（横轴取对数），虚线是 1。

无理数的逼近

竖线 x = α 穿过 p/q 的圆，当且仅当 |α − p/q| < 1/(2q²)，也就是表中 2q²|α − p/q| < 1。Legendre 定理：这样的 p/q 一定是 α 的渐近分数；相邻两个渐近分数里至少有一个满足它，所以竖线穿过无穷多个圆。连分数的讲解见 向日葵叶序。

显示

只画半径不小于这个值的圆，所以分母 q ≤ √(放大倍数 / 2r)，循环有上限。
下方的树和上面共用横轴：每个分数正好画在它的圆的下面，第 d 行是树的第 d 层。树的路径上金色是竖线 α 的路径（大点是渐近分数），白色是选中分数的路径。
