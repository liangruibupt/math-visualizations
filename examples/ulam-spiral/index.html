Ulam 素数螺旋 · 二次多项式的对角线

把 1, 2, 3, … 沿方形螺旋一圈圈排开，只点亮素数。素数会挤在一些斜线上：每条斜线的一半是一个二次多项式 4k² + bk + c 的取值（k 是第几圈）。单击一条斜线，看它的多项式和素数密度。

布局

点亮哪些数

随机对照：每个 n 以概率 1/ln n 点亮（素数定理给出的平均密度）。“随机奇数”只在奇数上抽，概率 2/ln n，保留了“素数都是奇数”这一条。

大小

从 41 开始，主对角线就是 Euler 的 m² + m + 41
缩小到一个像素装好几个格子时，像素颜色是这几个格子的平均，素数挤在一起的斜线就显得更亮

选中的斜线

单击 Ulam 螺旋上的一个格子：选中经过它、素数更密的那条斜线。
HL 常数 C 来自 Hardy–Littlewood 猜想 F：f(k) 是素数的“概率”约为 C / ln f(k)。C 由 f 对每个素数 p 的根数决定，这里乘到 p ≤ 400 万。
