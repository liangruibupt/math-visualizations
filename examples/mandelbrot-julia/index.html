Mandelbrot 集与 Julia 集

同一个迭代 z → zd + c，两种看法：左图固定 z₀ = 0、让 c 取遍平面；右图固定 c、让 z₀ 取遍平面。

参数

在左图单击设定 c；勾选“跟随鼠标”后移动鼠标即可实时改变
d = 2 是经典 Mandelbrot 集；d 越大，对称轴越多（d − 1 重旋转对称）
放大越深需要越多次迭代才能分辨边界
