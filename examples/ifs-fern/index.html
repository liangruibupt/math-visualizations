IFS 蕨叶 · 混沌游戏

从任意一点出发，每一步按概率 pi 随机挑一个仿射变换 x′ = Aix + ti 作用上去，再把这个点画出来。几百万步之后，点落在的地方就是这组变换的吸引子：一片蕨叶。

点数

调小可以慢慢看画面被点填满
按每个像素被击中次数的对数着色：log(1 + 次数) / log(1 + 最大次数)

仿射变换 x′ = a·x + b·y + e，y′ = c·x + d·y + f

单击左侧色块高亮这个变换：它产生的点着它的颜色，其余点变灰。概率 p 会自动归一化。

显示

虚线框是吸引子的包围盒 R，彩色平行四边形是 fi(R)。整片叶子正好是它在各个变换下的像拼起来的（自相似）。
