向日葵叶序 · 黄金角

第 n 颗种子放在角度 θ = n·α、半径 r = c·√n 处（Vogel 模型）。只改一个角度 α：137.5° 铺得又密又匀，差一点点就变成一根根直辐条。

发散角 α

α/360° 的连分数和渐近分数 p/q。q 就是会出现的螺线条数（或辐条数）。 曲线：均匀度 = 外侧种子的平均最近邻距离 ÷ 同密度六边形格点间距（1 = 最匀），取 N = 50、100、200、400、800 里最差的一个。金色虚线是黄金角，白线是当前 α；单击曲线可选角度。

种子

动画里新种子从中心长出，老种子保持角度不变、被向外推。

螺线族（斜列线）

在虚线圈附近数螺线。往里拖，条数沿 Fibonacci 数列变小。

圆柱叶序（菠萝 / 松果）

第 n 颗在 (n·α/360°, n·h)。h 越小排得越密，看到的螺线条数越大。
