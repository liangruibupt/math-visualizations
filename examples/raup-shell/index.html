Raup 贝壳卷曲模型

转一圈后生成管口放大的倍数
管口内缘 / 外缘到中轴的距离比；0 = 贴着中轴
沿中轴的下移量（相对管口中心半径）；0 = 平旋
可以少于 1 圈，例如双壳

管口形状

沿中轴方向 / 径向的半轴之比；1 = 圆，>1 竖长，<1 扁
管口在径向剖面内的旋转角度
超椭圆指数：1 = 菱形，2 = 椭圆，越大越方
占管口尺寸的比例，随生长等比变厚
开启后，上面三项是壳口处的形状，下面三项是壳顶处的形状，中间的过渡快慢由下面的“过渡曲线 γ”控制
0 = 按圈数均匀过渡，1 = 按管口尺寸线性过渡，越大变化越集中在壳口

壳表纹理

沿螺旋方向延伸的纵肋，绕管口一周的条数；0 = 无
平行于壳口的横纹，强弱略有起伏；0 = 无

内部构造

头足类（鹦鹉螺、菊石）把旧的螺管用隔板封成气室；最后约 1/3 圈是住室，没有隔板
体管是穿过各隔板、连通所有气室的细管，用来调节浮力

显示

调低可看到内部的早期螺层
剖切面始终包含中轴，绕中轴旋转；截面按管壁实体填充
左键拖动旋转 · 滚轮缩放 · 右键平移
