Logistic 映射 · 倍周期分岔

只有一行：x → r·x(1 − x)。左上是蛛网图，右上是 x 随步数的变化，下面是分岔图：每个 r 迭代很多步以后 x 落在哪些值上。r 增大时周期 1 → 2 → 4 → 8 → … 越分越快，在 r∞ ≈ 3.5699 进入混沌。最下面的 Lyapunov 指数 λ > 0 就是混沌。

参数

f² 与对角线的交点就是 2-周期点，f⁴ 的就是 4-周期点；周期 3 窗口里用 k = 3

倍周期分岔点与 Feigenbaum 常数

rn：周期 2n−1 的轨道失稳（乘子 = −1），分裂成周期 2n。δn = (rn − rn−1) / (rn+1 − rn)，相邻两段分岔间距之比。
